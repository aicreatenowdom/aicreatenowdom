## ArtifactTrust Pro GUI

<p>
  <a href="https://trustprogui.com/">
    <img src="assets/artifacttrust-pro-gui.png" alt="ArtifactTrust Pro GUI blue and silver signing seal" width="100">
  </a>
</p>

**Your software. Your signature. A guided way to sign.** ArtifactTrust Pro GUI **3.1** brings Microsoft Artifact Signing to a focused Windows interface. Sign one software file with a PDF verification report, or process up to 50 files in a batch without PDF reports. The app prepares its bundled prerequisites on first launch and guides you through connecting your existing signing resources.

**Free for everyone.** Coffee tips are optional. An eligible Microsoft account, subscription and configured signing resources are required; Microsoft service charges are separate. This is an independent application from AI Creations Now Software Development.
